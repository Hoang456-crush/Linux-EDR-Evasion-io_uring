 RULE 1 of 13: Phase 1 — io_uring_setup Chokepoint
 Rule Type: Custom query (KQL)
═══════════════════════════════════════════════════════════════════════════

  ── SCREEN 1: Define rule ──

  1. Chọn Rule type: ○ Custom query   ← Click cái này
                     ○ Machine Learning
                     ○ Threshold
                     ○ Event Correlation
                     ○ Indicator Match
                     ○ New terms
                     ○ ES|QL
                     ○ Saved Query

  2. Source:
     Index patterns: [ auditbeat-* ]
     → Click ô "Index patterns", xóa default, gõ: auditbeat-*
     → Nếu không thấy suggest → gõ xong nhấn Enter

  3. Custom query (KQL):
     ┌─────────────────────────────────────────────────────────────┐
     │ auditd.data.syscall:"io_uring_setup" AND NOT               │
     │ process.executable:("/usr/sbin/nginx" OR                    │
     │ "/usr/bin/postgres" OR "/usr/bin/fio")                      │
     └─────────────────────────────────────────────────────────────┘
     → Copy-paste vào ô query

  4. Click [Preview results] (phía dưới query box)
     → Nếu thấy kết quả = query đúng
     → Nếu 0 results = bình thường (chưa chạy attack)

  5. Click nút [Continue] (góc phải dưới)

  ── SCREEN 2: About rule ──

  6. Name (bắt buộc):
     [Purple Team] Phase 1 — io_uring_setup Chokepoint

  7. Description:
     Detects io_uring_setup() syscall — the MANDATORY chokepoint
     that every io_uring evasion toolkit must call before any
     async operations become invisible to syscall monitors.
     Maps to phase1_init() in evasion_ops.c.

  8. Severity: Click dropdown → chọn "High"

  9. Risk score: Kéo slider đến 73 (hoặc gõ 73 vào ô)

  10. Expand "Advanced settings" (click mũi tên ▶):

      → MITRE ATT&CK threats: Click [Add MITRE ATT&CK threat]
         Tactic:    Defense Evasion
         Technique: Rootkit (T1014)

      → Tags: Click vào ô Tags, gõ từng tag rồi nhấn Enter:
         io_uring
         T1014
         Defense Evasion
         Phase1
         Purple-Team

  11. Click [Continue]

  ── SCREEN 3: Schedule rule ──

  12. Runs every:                 1    minute   (đổi từ 5 → 1)
      Additional look-back time:  1    minute   (đổi từ 1 → 1)

  13. Click [Continue]

  ── SCREEN 4: Rule actions (optional) ──

  14. Bỏ qua (hoặc add Slack/Email notification nếu muốn)
  15. Click [Create & enable rule]

  ✅ Rule 1 DONE! → Bạn sẽ thấy rule page hiện "Active"
  📸 Screenshot màn hình này cho thesis!
